# 5. Тестирование

> **Кратко:** 26 тест-кейсов, 26 автотестов на pytest — все проходят. При ручной проверке в Docker нашлась и исправлена ошибка 500.

## 5.1 План тестирования

| Пункт | Описание |
|-------|----------|
| **Что тестируем** | авторизацию, права доступа, питомцев, услуги, запись и отмену, проверку входных данных, интерфейс |
| **Автотесты** | `backend/tests/test_api.py` — pytest + TestClient |
| **Ручные тесты** | интерфейс в браузере, запуск через Docker |
| **Окружение** | Python 3.12–3.14, macOS, Docker Desktop, Chrome |
| **Тестовые данные** | у каждого автотеста своя временная база SQLite; время «сейчас» зафиксировано: 01.12.2026 10:00 |
| **Критерий успеха** | все автотесты проходят, все тест-кейсы дают ожидаемый результат |

**Запуск автотестов:**

```bash
cd backend
python -m pytest -v
```

## 5.4 Найденные и исправленные ошибки

| № | Что нашли | Как проявлялось | Причина | Исправление |
|:-:|-----------|-----------------|---------|-------------|
| 1 | Ошибка 500 на любом запросе с базой | при ручной проверке в Docker страница «Мои питомцы» показала «Ошибка 500» | FastAPI открывал соединение с SQLite в одном потоке, а запрос выполнял в другом, а SQLite такое запрещает | в `db.py` добавлен `check_same_thread=False` (у каждого запроса своё соединение, поэтому это безопасно); после исправления 40 запросов подряд — все 200 |
| 2 | pytest не находил тесты | `no tests ran` при первом запуске | Python не видел пакет `app` из папки `tests` | добавлен `pytest.ini` с `pythonpath = .` |
| 3 | Таблица записей у администратора съезжала | колонка «Статус» занимала полтаблицы | общий стиль задавал всем `select` ширину 300px | для `select` внутри таблицы ширина стала автоматической |
| 4 | В Swagger все методы были в одной группе «default» | искать нужный метод было неудобно | у эндпоинтов не было тегов | методы разбиты на группы: Авторизация, Питомцы, Услуги, Записи |
