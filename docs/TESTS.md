# Тестирование

## 1. План тестирования

**Что тестируем:** авторизацию, питомцев, услуги, запись и отмену, права доступа, проверку входных данных.

**Виды тестирования:**
- автоматические тесты API и бизнес-логики (pytest, `backend/tests/test_api.py`);
- ручное тестирование интерфейса в браузере по тест-кейсам ниже.

**Окружение:** Python 3, временная база SQLite для каждого автотеста. В автотестах время «сейчас» зафиксировано: 01.12.2026 10:00.

**Запуск автотестов:**

```bash
cd backend
python -m pytest -v
```

**Критерий успеха:** все автотесты проходят, все тест-кейсы дают ожидаемый результат.

## 4. Найденные и исправленные ошибки

| № | Ошибка | Как исправили |
|---|--------|---------------|
| 1 | Можно было зарегистрироваться дважды с одним email, написав его другими буквами (Ivan@ и ivan@) | email приводится к нижнему регистру при регистрации и входе |
| 2 | Запись, которая начинается ровно в момент окончания другой, считалась пересечением | условие пересечения сделано строгим: `start1 < end2 and start2 < end1` |
| 3 | Длинная услуга могла закончиться после закрытия салона (19:30 + 60 мин) | проверяется время окончания, а не только начала |
| 4 | При изменении цены услуги менялась цена в старых записях | цена копируется в запись при её создании |
| 5 | При удалении питомца с активной записью запись пропадала без предупреждения | удаление запрещено, пока есть активные записи |
| 6 | Админ мог вернуть отменённую запись в статус «Записан», хотя время уже заняли | перед возвратом проверяется, что время свободно |
