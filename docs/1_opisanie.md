# 1. Описание проекта

> **Кратко:** «Пушистик» — сайт груминг-салона, где владелец сам записывает питомца на услугу в свободное время, а администратор видит расписание всего салона.

## 1.1 Название и назначение

| | |
|---|---|
| **Название** | Груминг-салон «Пушистик» |
| **Тип** | веб-приложение (сайт + REST API) |
| **Назначение** | онлайн-запись питомцев на груминг и ведение расписания салона |
| **Автор** | Царегородцев Петр Васильевич |

## 1.2 Какую проблему решает

Небольшие салоны часто записывают клиентов по телефону в тетрадь. Отсюда проблемы:

| Проблема сейчас | Как решает «Пушистик» |
|-----------------|-----------------------|
| клиент не знает, какое время свободно, и звонит несколько раз | на сайте видны только свободные слоты на выбранную дату |
| две записи на одно и то же время | сервер не даёт создать пересекающиеся записи |
| администратор тратит время на звонки | клиент записывается и отменяет запись сам |
| данные о питомцах теряются | у клиента в профиле хранится список питомцев (вид, порода, вес) |
| цены меняются, и непонятно, сколько платить | цена фиксируется в записи в момент записи |

## 1.3 Целевая аудитория и пользователи

**Целевая аудитория:** владельцы собак и кошек, которые пользуются услугами груминга, и сотрудники небольших салонов.

| Роль | Кто это | Что может |
|------|---------|-----------|
| 👤 Гость | любой посетитель сайта | смотреть услуги, зарегистрироваться, войти |
| 🐶 Клиент | владелец питомца | вести список питомцев, записываться, смотреть и отменять свои записи |
| 🛠 Администратор | сотрудник салона | вести каталог услуг, видеть все записи с контактами, менять статус, отменять записи |

## 1.4 Основные функции

| Код | Функция | Роль |
|:---:|---------|------|
| F1 | Регистрация, вход и выход | все |
| F2 | Управление питомцами (добавить, изменить, удалить) | клиент |
| F3 | Каталог услуг (добавить, изменить, отключить, удалить) | администратор |
| F4 | Запись на услугу с подбором свободного времени | клиент |
| F5 | Просмотр и отмена своих записей | клиент |
| F6 | Все записи салона и смена статуса | администратор |

## 1.5 Функциональные требования

| Код | Требование | Критерий приёмки |
|:---:|------------|------------------|
| FR-1 | Регистрация по email, паролю, имени и телефону | после регистрации пользователь сразу входит в систему; повторный email — ошибка 409 |
| FR-2 | Вход и выход | при неверном пароле — 401; после выхода старый токен не работает |
| FR-3 | CRUD питомцев | клиент видит и меняет только своих питомцев; питомца с активной записью удалить нельзя |
| FR-4 | CRUD услуг | менять услуги может только администратор; услугу с записями нельзя удалить, только отключить |
| FR-5 | Свободные слоты | на выбранную дату показываются только свободные отрезки с учётом длительности услуги |
| FR-6 | Создание записи | нельзя записаться в прошлое, вне рабочего времени и на занятое время |
| FR-7 | Отмена записи | клиент — не позже чем за 2 часа до начала, администратор — в любое время |
| FR-8 | Статусы записи | администратор меняет статус: «Записан», «Выполнено», «Отменено» |

## 1.6 Нефункциональные требования

| Категория | Требование |
|-----------|------------|
| Безопасность | пароли хранятся только как хеш PBKDF2-SHA256 с солью |
| Безопасность | доступ к API по токену `Authorization: Bearer`, токен удаляется при выходе |
| Безопасность | права проверяются на сервере: чужие питомцы и записи возвращают 404 |
| Надёжность | все входные данные проверяются на сервере (Pydantic), ошибки — понятным текстом на русском |
| Документация | описание API в Swagger по адресу `/docs` |
| Развёртывание | запуск одной командой `docker compose up --build` |
| Удобство | интерфейс без сборки и фреймворков, работает в Chrome, Firefox, Edge |
| Производительность | обычный запрос выполняется меньше чем за 1 секунду |
